A tiny Python program that prints exactly one line: an invented superpower that sounds incredible and is completely useless.

## The line

> I can read any mind on Earth with perfect, word-for-word clarity, but only the mind of who I was exactly 3.7 seconds ago, and only thoughts I have already forgotten.

Perfect telepathy. Zero use: the only mind it can reach is your own, 3.7 seconds in the past, and only the thoughts you no longer remember having.

## Run it

```sh
python3 main.py
```
